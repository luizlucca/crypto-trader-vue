# CryptoPro Desktop

Aplicação Electron com renderer Vue 3 e processos auxiliares TypeScript/RxJS.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Qualidade e build

```sh
npm test
npm run typecheck
npm run build
```

## Pacote Linux

```sh
npm run package:linux
```

Os artefatos AppImage e Debian são gravados em `release/`.
